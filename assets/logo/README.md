# Logo

| File | Use |
|---|---|
| `keyhammer-icon.svg` | Main mark, for light backgrounds |
| `keyhammer-icon-dark.svg` | Mark for dark backgrounds |
| `keyhammer-icon-mono.svg` | Single colour (black) |
| `keyhammer-icon-white.svg` | Single colour (white), for dark or coloured backgrounds |
| `keyhammer-icon-512.png`, `keyhammer-icon-1024.png` | Raster exports with a transparent background |
| `favicon.ico`, `favicon-32.png`, `favicon-180.png` | Browser and touch icons |
| `social-preview.png` | 1280x640 card for the repository's social preview (uploaded by hand in Settings) |

Colours: indigo `#2F2E74`, amber `#F2AB1D`; on dark backgrounds the indigo is lightened to `#8C88F0`.
The documentation site serves this folder from its root (see `staticDirectories` in `website/docusaurus.config.js`).
